# Anima — Google Play Store Listing (ASO)

> Goal: keep the new app from being buried under the well-known "Anima" AI-companion app by
> putting real search keywords into the **3 indexed fields (App name · Short description · Full description)**.
> Google Play has **no separate keyword field** — it indexes these 3 fields + reviews/installs.
> **Store-listing edits need NO AAB rebuild** — they apply on save (search indexing takes hours to a few days).

Core message (per user): **"Your future becomes what you believe."** (나의 미래는 내가 믿는 대로 된다)
Positioning: personalized daily affirmations & motivation from "your future self" + today's goals; real, verified
mentor quotes (no fake quotes); daily intention writing + wins journal; no ads; one-time purchase, lifetime.

> NOTE: The lock-screen / home-screen quote **widget is intentionally excluded** from this listing per user.
> (The web landing `app/page.tsx` still markets the widget — align it later if the widget is truly dropped.)

---

## 1) App name — max 30 chars

Highest search weight. Brand "Anima" + a top keyword, clearly separating it from the AI-friend "Anima".

### ✅ Confirmed: `Anima: Daily Affirmations`  (25 chars — strongest search term, no collision)

Alternatives (for reference):
- `Anima: Affirm Your Future` (25) — blends the belief theme + affirmations keyword
- `Anima – Affirmations & Mindset` (30) — two keywords packed
- `Anima: Believe & Become` (23) — most on-theme, weaker on search keywords

> Avoid keyword-stuffing the title (policy risk). 1–2 keywords, clean.

## 4) Non-text ASO levers (biggest for a brand-new app)

1. **Early installs & ratings** — the strongest ranking signal. Share the production link
   (`https://play.google.com/store/apps/details?id=com.michaelkim.anima`) to gather first installs & reviews.
2. **Screenshots 1–2** — drive conversion. Lead with the affirmation / "future self" message screen.
3. **Locale** — this listing is English (global, 177 countries). A Korean listing can mirror the same
   structure as a separate locale if desired.
4. **No title stuffing** — policy penalties hurt visibility.

## 5) Where to paste (Play Console)
Grow → Store presence → Main store listing → App name / Short description / Full description → Save
(no rebuild required).
